# Personnages — crédits

## Ranger, Fencer, Air Raider (`ranger.glb`, `fencer.glb`, `airraider.glb`)

Modélisés dans Blender par `tools/blender/wingdiver/build_char.py --char …` (tenues dans `ranger.py`, `fencer.py`,
`airraider.py` : travail original du projet). Corps, visages, yeux, sourcils, cils, cheveux courts, peau et unités
d'expression : **MakeHuman** (CC0), via **MPFB 2** (outil seulement), comme pour la Wing Diver ci-dessous.

## Wing Diver (`wingdiver.glb`)

Modélisée dans Blender par `tools/blender/wingdiver/build_char.py` (combinaison, armure, bottes, unité de vol, matériaux et
textures cuites : travail original du projet).

Le corps, le visage, les yeux, les sourcils, les cils, les dents, la langue, la queue de cheval, la texture de peau et les
unités d'expression du visage viennent de **MakeHuman** (actifs système, licence **CC0**), générés avec l'extension Blender
**MPFB 2** (code sous licence GPL v3, utilisé seulement comme outil : il n'est pas distribué avec le jeu).

- MakeHuman : https://www.makehumancommunity.org — actifs « MakeHuman system assets » (CC0).
- MPFB 2 : https://extensions.blender.org/add-ons/mpfb/
